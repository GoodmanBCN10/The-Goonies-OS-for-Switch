# 🎮 The Goonies OS for Nintendo Switch

**A clean and lightweight CFW pack for Nintendo Switch.**

The Goonies OS is a pre-configured CFW pack that brings together the essential tools needed to manage and maintain a modded Nintendo Switch.

The goal is simple: **everything you need, without unnecessary extras.**

## ✨ What's included

### ⚙️ System

* **Atmosphère** — Custom Firmware
* **Hekate** — Bootloader and system tools

### 🧰 Essential Tools

* **DBI** — Installation, MTP and console management
* **The Goonies APP** — All-in-one toolbox with multiple utilities
* **Daybreak** — Firmware update utility
* **Quick Reboot** — Quick and easy reboot options
* **DNS Setter** — Configure DNS settings
* **DNS Tester** — Check and test DNS configuration

## 🦾 The Goonies APP

The Goonies APP is the main utility included in the pack.

It combines several useful functions in a single application, providing an easy way to manage different aspects of the console without needing multiple separate homebrew applications.

> **One app. Multiple tools. One simple interface.**

## 📦 Philosophy

The Goonies OS is designed around three principles:

* **Clean** — Only essential tools.
* **Simple** — Easy to understand and use.
* **Ready** — Pre-configured and ready to go.
